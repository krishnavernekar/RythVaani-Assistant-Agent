RythuVaani — Complete Project Summary

Date: November 19, 2026 | Platform: React Native (Expo) | Languages: Telugu, English, Hindi

1. Project Overview

RythuVaani is an AI-powered smart agronomy companion for farmers in Andhra Pradesh and Telangana. Features:

  • Voice-first AI agronomist consultation (Sarvam STT/TTS + LLM)
  • Crop health scanner (Gemini Vision)
  • Live mandi prices (Data.gov.in Agmarknet)
  • Government scheme eligibility verifier (6 AP/TG schemes)
  • Farmer profile & vault (bookmarks, question history)
  • Real OTP authentication (MSG91)
  • Cloud database sync (Supabase PostgreSQL)

9. Key Design Decisions

  1. Zero-PII: Never collect Aadhaar, OTP, or bank details
  2. Offline-first: AsyncStorage cache + async cloud sync
  3. Fallback chains: FreeLLM → Gemini → Offline KB
  4. Bilingual: All UI and AI in Telugu + English (+ Hindi)
  5. Voice-first: Sarvam STT/TTS for non-literate farmers
  6. No synchronous setState in useEffect
  7. Global audio guard: Navigation stops all audio
